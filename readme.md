# The 7th Reason
This is a bot, made for **6 Reasons Not To Play TF2**, an OzFortress 6s team.

## Commands
- `/poll_availability`
- `/announce_event <Event type> <Day> <Opponent>`
- `/confirm_event <Event type> <Day> <Time> <Opponent>`

## Usage
1. Download repository
2. Add bot token to a `Secrets.toml` file as `BOT_TOKEN`
3. Deploy the bot using [Shuttle](https://www.shuttle.dev/)
4. Run!
